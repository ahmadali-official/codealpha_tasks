# Hi, I'm Ahmad 👋 — This is My Portfolio Website

This is my personal portfolio website. I built it to show who I am, what I've learned,
and what I've built so far as a Computer Science (AI & ML) student. It's made with
plain **HTML, CSS, and JavaScript** — no frameworks, no build tools, nothing complicated.
Just open it and it works.

## 🔗 Live Site

Link here:

```
https://github.com/ahmadali-official/codealpha_tasks.git
```

## 📸 What's Inside

The website has 10 sections you can scroll through:

1. **Home** – A quick intro and buttons to jump to my projects, resume, or contact info
2. **About** – A bit more about me and what I'm looking for
3. **Education** – My academic background, shown as a timeline
4. **Skills** – Languages, web tech, AI/ML tools, and other things I work with
5. **Projects** – Things I've built, with filters so you can view by category
6. **Experience** – Internships and hands-on work
7. **Certifications** – Courses and achievements
8. **Resume** – A place to view or download my resume
9. **Services** – What I can help with
10. **Contact** – A form to reach out, plus my email and socials

It also has:
- 🌗 A **light mode** and a true **AMOLED black dark mode** (your choice is remembered next time you visit)
- 📱 Works nicely on phones, tablets, and desktops
- ✨ Smooth animations as you scroll
- 🖱️ A project filter and a details popup for each project
- 🖼️ A certificate viewer

## 🛠️ Built With

- **HTML5** – page structure
- **CSS3** – all the styling, colors, layout, and animations (no CSS framework)
- **Vanilla JavaScript** – theme switching, animations, filtering, and form checks (no JS framework)

## ✏️ Before You Use This Yourself

If you're customizing this for your own portfolio, here's what to change:

- Open `index.html` and replace anything written in **CAPS**, like `YOUR EMAIL`,
  `YOUR PHONE NUMBER`, `YOUR GITHUB`, and the project/certificate details, with your own info.
- Add your own photo, project screenshots, and certificate images where you see a
  placeholder box that says things like `YOUR PROFILE IMAGE`.
- Drop your real `resume.pdf` and certificate PDFs into the same folder — the
  download buttons are already linked to those file names.
- Want a different color scheme? Open `style.css` and look for the `:root` section
  near the top — that's where all the colors are defined in one place.

## 🚀 How to Run It Locally

You don't need to install anything. Just:

1. Download or clone this folder
2. Double-click `index.html`
3. It opens straight in your browser
